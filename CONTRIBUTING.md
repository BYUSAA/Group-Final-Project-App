# Contributing to StudyLink

- Branches: `feature/<name>`, `fix/<name>`, or member branches such as `byusa-work`.
- Commit prefixes: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`.
- PRs describe changes, test steps, and include UI screenshots.
- Run `dart format --output=none --set-exit-if-changed .`, `flutter analyze`, and `flutter test`.
- Never commit Firebase service-account files, signing keys, or private credentials.
